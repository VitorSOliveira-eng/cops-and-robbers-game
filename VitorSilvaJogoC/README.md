Para rodar este jogo 2D de perseguição policial, onde o objetivo é sobreviver o maior tempo possível fugindo da viatura, compile o projeto executando o comando ./build.bat e inicie a partida com ./game.exe. Durante a fuga, utilize as setas do teclado para controlar o seu veículo e faça drifts estratégicos para desviar rapidamente e quebrar o traçado da polícia. Use o cenário a seu favor: tente atrair o carro de perseguição para passar por cima das poças de óleo espalhadas pelo mapa, pois isso aplicará um efeito de lentidão na viatura e te dará a vantagem necessária para escapar e prolongar a sua sobrevivência.
